# «بازوكا» - Authoritative Multiplayer Game Server 🚀

خادم الألعاب الحقيقي للعبة «بازوكا» (Android Native Kotlin Multiplayer Game).

يعتمد هذا الخادم على بروتوكول WebSocket لاتصالات الوقت الفعلي (Real-time Multiplayer) وواجهات برمجة التطبيقات REST API مع تخزين موثوق للبيانات.

---

## 🌟 المميزات
- **إدارة الجلسات الحية**: غرف انتظار متعددة اللاعبين تتسع حتى 6 لاعبين.
- **مؤقت الثواني الـ 7 الصارم**: احتساب تنازلي authoritative مركزي لا يسمح بالاحتيال.
- **ترسانة الأسلحة**: مسدس عادي، قاذف بازوكا، إعطاء البازوكا، قاذف بازوكا ناري (حظر جولتين).
- **المبارزة النهائية (حجرة ورقة مقص)**: نظام اختيار سري وحسم فوري للفائز.
- **نقاط النصر (Victory Points)**: سجل إحصائيات، متجر، قائمة أصدقاء.
- **جاهز للنشر السحابي المجاني**: يدعم النشر بضغطة زر واحدة على Render أو Railway.

---

## 🛠️ التشغيل محلياً (Local Setup)

1. تثبيت الحزم:
```bash
npm install
```

2. بدء تشغيل الخادم:
```bash
npm start
```
سيعمل الخادم على المنفذ `8085` (أو المنفذ المحدد في متغير البيئة `PORT`).

---

## ☁️ النشر المجاني على Render.com (خطوة بخطوة)

1. توجه إلى [dashboard.render.com](https://dashboard.render.com) وقم بتسجيل الدخول بحساب GitHub.
2. اضغط على **New +** ثم اختر **Web Service**.
3. اختر هذا المستودع (`bazooka-server`).
4. أدخل الإعدادات التالية:
   - **Name**: `bazooka-server`
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: `Free`
5. اضغط **Deploy Web Service**.
6. بعد انتهاء النشر، ستحصل على رابط مجاني دائم ومحمي بشهادة SSL تلقائياً بصيغة:
   `https://bazooka-server-xxxx.onrender.com`
7. قم بوضع هذا الرابط مباشرة في شاشة إعدادات السيرفر داخل تطبيق «بازوكا».
